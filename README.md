# github-final-project

## Simple Interest Calculator

A Bash script that calculates simple interest from user input. It is the first project moved from SVN to Git as part of our micro-finance startup's mission to empower and create opportunities for low-income individuals.

### Formula

```
Simple Interest = (Principal x Rate x Time) / 100
```

- **Principal:** the amount borrowed or invested
- **Rate:** the annual rate of interest, as a percentage
- **Time:** the time period, in years

### Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script asks for the principal, rate, and time, then prints the simple interest and the total amount.

### Example

```
Enter the principal amount: 1000
Enter the annual rate of interest (%): 5
Enter the time period (in years): 2

Simple interest: 100.00
Total amount (principal + interest): 1100.00
```
