# Contributing to the Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork this repository.
2. Create a branch for your change: `git checkout -b my-change`
3. Make your changes and test the script.
4. Commit with a clear message: `git commit -m "Describe your change"`
5. Push your branch: `git push origin my-change`
6. Open a pull request describing what you changed and why.

## Reporting bugs

Open an issue with the steps to reproduce the problem, what you expected, and what happened instead.

## Suggesting ideas and enhancements

Open an issue describing the idea and how it would help users.

## Code of Conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
